## Matúš Kališ

Founder of **[ShipFourteen](https://ship14.com)**, a web studio from Bratislava. I design and build fast, custom websites for businesses, and the agent pipeline that makes them: research, design, build and gates run by coding agents that I orchestrate, then checked by hand.

Every site we ship passes the same bar before anyone sees it: phone first, measured with Lighthouse (our samples score 97 to 100 on mobile), 0 accessibility violations, a strict security baseline (CSP, HSTS, no exposed files), and structured data for Google and AI search.

### Spotlight: InVenture Mind

With my InVenture Mind team I am developing an EEG sleep headband concept: it recognises the sleep phase and times a quiet sound cue with a wake-up check. The lead hypothesis is help with nightmares; sleep quality and learning are explored alongside.
